# Матрица доступа — вариант 1

Обозначения: **C** — Create, **R** — Read, **U** — Update, **—** — нет доступа.

## Исходная матрица

### `prescription`

| Атрибут | Врач | Провизор |
| --- | --- | --- |
| `prescription_number` | R, C | R |
| `disease_code` | R только для своих рецептов, C | — |
| `patient_name` | R только для своих рецептов, C | R |
| `issue_date` | R, C | R |
| `doctor_name` | R, C | — |
| `validity_days` | R, C, U только для своих рецептов | R |
| `drug_name` | R, C | R |
| `drug_code` | R, C | R |
| `is_used` | R, C | R, U только для действующих |
| `pharmacy_number` | R, C | R, U только для действующих |

Горизонтальные ограничения:

- врач видит `disease_code` и `patient_name` только в рецептах, где `doctor_name = текущий врач`;
- врач изменяет `validity_days` только в своих рецептах;
- провизор изменяет `is_used` и `pharmacy_number` только пока рецепт не использован и не истёк срок действия.

### `pharmacy`

| Атрибут | Врач | Провизор |
| --- | --- | --- |
| `pharmacy_number` | — | R |
| `pharmacist_name` | — | R |
| `city` | — | R |
| `address` | — | R |

Доступ врача к `pharmacy` в задании не определён, поэтому не выдаётся.

## Реализованная матрица

| Ограничение | Средство | Результат |
| --- | --- | --- |
| Врач: чтение обычных полей всех рецептов | `GRANT SELECT` + `doctor_select_policy` | Реализовано |
| Врач: чтение `disease_code` и `patient_name` только своих рецептов | Требуется комбинация «строка + столбец» | Не реализовано встроенными средствами; выдано чтение этих полей всех рецептов |
| Врач: добавление рецептов | `GRANT INSERT` + `doctor_insert_policy` | Реализовано; `doctor_name` обязан равен `current_user` |
| Врач: изменение `validity_days` только своих рецептов | `GRANT UPDATE (validity_days)` + `doctor_update_policy` | Реализовано |
| Провизор: чтение рецептов без `doctor_name` и `disease_code` | `GRANT SELECT (перечень столбцов)` | Реализовано |
| Провизор: изменение `is_used` и `pharmacy_number` действующих рецептов | `GRANT UPDATE (...)` + `pharmacist_update_policy` | Реализовано |
| Провизор: чтение аптек | `GRANT SELECT ON pharmacy` | Реализовано |

Отклонение от исходной матрицы одно: врач получает право читать `disease_code` и `patient_name` во всех строках, потому что PostgreSQL RLS фильтрует строки, а не столбцы; сочетание «в одной строке столбец виден, в другой скрыт» без представления или функции не выражается.
