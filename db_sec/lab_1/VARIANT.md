# Выбранный вариант задания — №1

## Данные

### Отношение 1 — рецепты

- Номер рецепта — PK.
- Код заболевания.
- ФИО пациента — AK1.
- Дата выписки — AK1.
- ФИО врача.
- Срок действия в днях — если есть.
- Наименование лекарства.
- Код лекарства.
- Признак того, что рецепт использован.
- Номер аптеки — FK.

### Отношение 2 — аптеки

- Номер аптеки — PK.
- ФИО провизора — AK1.
- Город аптеки — AK2.
- Адрес аптеки — AK2.

## Права доступа

### Врач

- Видит все данные рецептов, кроме ФИО пациента и кода заболевания.
- ФИО пациента и код заболевания видит только для рецептов, которые
  выписал сам.
- Может выписывать, то есть добавлять, рецепты.
- Может изменять срок действия только в своих рецептах.

### Провизор

- Видит все данные рецептов, кроме ФИО врача и кода заболевания.
- Может изменять признак использования рецепта и номер аптеки только
  для ещё действующих на момент изменения рецептов.
